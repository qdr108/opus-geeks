# Opus Geeks Redesign

Premium Next.js redesign concept for Opus Geeks, built for sales, hiring, brand image, and international client trust.

## Stack

- Next.js
- Tailwind CSS
- Framer Motion
- Sanity-ready content layer
- Lucide icons

## Features

- AI-style project estimator
- Before/after redesign slider
- Interactive product journey
- Filterable portfolio case studies
- CEO message/video section
- Project risk prevention section
- Mini project progress dashboard
- Dark/light mode
- Fully responsive layout

## Run Locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.
